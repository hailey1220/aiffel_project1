# 과제 제출 — 자기 도메인 전달 형식 채우기

[도메인 맥락]

나는 네이버 블로그 제휴마케팅 도메인 1년 차이고, 시즌에 맞는 제휴 상품을 고르고 글쓰기 재료를 준비하는 작업을 자동화/정리하고 싶습니다.


[네 동작 분석]
1. 분해
- 데이터랩에서 시즌 키워드를 정한다
- 쇼핑 커넥트나 세시간전에서 후보를 검색한다
- 후기 수와 평점이 높은 상품 2~3개를 추린다
- 실제 후기를 확인한다
- 블로그 1~3페이지의 경쟁도를 확인한다
- 최종 상품과 글 형식을 정한다

  

2. 패턴
- 시즌 → 수요 → 후보 → 후기 검증 → 선택 순서는 항상 같다.
- 수요는 있지만 경쟁 글이 포화되지 않은 상품을 고른다.
- 홍보 문구와 실제 후기가 맞는지 확인한다.
- 사소한 단점은 탈락시키지 않고 글의 아쉬운 점으로 쓴다.

  

3. 추상화
과정과 기본 기준은 같고, 상품군에 따라 아래 항목만 달라진다.

항목	리빙	여행
시즌	날씨·계절	연휴·꽃·단풍
후보 출처	쇼핑 커넥트	세시간전
검증 항목	결함, 홍보 문구 일치 여부	만족 포인트, 쿠폰
경쟁 대응	다른 제품으로 교체	서브 키워드 추가



4. 알고리즘
- 시즌 키워드를 정한다.
- 리빙은 쇼핑 커넥트, 여행은 세시간전에서 검색한다.
- 후기 100개 미만은 빼고, 상위 2~3개를 고른다.
- 후보를 검증한다.
낮은 별점 20% 이상 + 부정 후기 10개 중 3개 이상 → 탈락
리빙: 결함이 있거나 홍보 문구와 후기가 다르면 → 탈락
여행: 쿠폰가가 공식 홈페이지보다 비싸면 → 탈락

- 모두 탈락하면 → 다음 순위 후보로 다시 검증
블로그 1~3페이지 점유율이 70% 이상이면
서브 키워드를 제목에 추가하여 틈새를 확보한다.

- 직접 써 봤으면 리뷰·비교형, 아니면 정보성 글로 정한다.
- 멈춤 조건: 후기 100개 이상인 후보가 더 없으면 1번으로 돌아간다.
